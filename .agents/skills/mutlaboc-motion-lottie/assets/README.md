# Assets for mutlaboc-motion-lottie

Put temporary reference assets here only when they are needed for animation generation.

Do not store final Android production assets here.

Final app assets must go to:

- `app/src/main/res/raw` for `.json` / `.lottie`;
- `app/src/main/res/drawable*` for drawable assets.

Do not commit large temporary renders, preview videos, or raster sequences unless the task explicitly requires them.
