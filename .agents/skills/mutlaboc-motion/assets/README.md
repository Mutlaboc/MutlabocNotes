# Assets for mutlaboc-motion

Put temporary reference assets here only when they are needed for animation generation (AI-generated GIFs, sprite sheets, frame drafts).

Do not store final Android production assets here.

Final app assets must go to `app/src/main/res/drawable-nodpi/` as lossless WebP frames (`name_NN.webp`), produced via `scripts/prepare_frames.py`.

Do not commit large temporary renders, preview videos, or intermediate GIFs.
